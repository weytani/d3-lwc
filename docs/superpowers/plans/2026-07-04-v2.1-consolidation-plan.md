# v2.1.0 Consolidation & Expansion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v2.1.0: trimmed test suite, quality-fixed charts, 10 new charts (30→40), GraphQL `fetchMode` on every chart, and a comprehensive docs set.

**Architecture:** Everything additive. GraphQL self-fetch extends the proven d3BarChart A-pattern (reactive `gqlQuery` getter + `@wire(graphql)`, un-provisioned unless `fetchMode="graphql"`); new charts clone in-family donors; quality fixes wire advertised-but-dead surface using in-repo donor patterns (never removing `@api`/meta properties — live-page deploy block + semver).

**Tech Stack:** LWC (API 65.0), D3 v7 (static resource `d3`), jest (`sfdx-lwc-jest` + v2 `lightning/graphql` stub), Salesforce UI API GraphQL.

**Spec:** `docs/superpowers/specs/2026-07-04-v2.1-consolidation-design.md` (committed `0c090a9`). Task-level audit evidence (file:line) lives in the spec §2a/§3a/§5a-b.

## Global Constraints (every task inherits these)

- Full suite only: `npm test` (~3 s). `--testPathPattern` does NOT narrow in this repo.
- Format only your files: `npx prettier --write <file>...` — NEVER `npm run prettier` (whole-repo reformat).
- Lint per path: `npx eslint <dir>...` — NEVER `npm run lint` (broken stale `aura/**` glob).
- Commits: conventional format, imperative, present tense, ending with `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`. husky+lint-staged runs prettier/eslint/related-jest on staged files. NEVER `--no-verify`, NEVER bypass hooks; if a hook fails, fix the cause.
- NEVER remove an existing `@api` property or meta `<property>` (live-page deploy block; semver). Additions and description-text edits are safe.
- LWC1107: no `@api` property whose name starts with `data`. The mode prop is `fetchMode`.
- `@wire(graphql)` requires apiVersion 65.0 in the bundle meta (all bundles already are — verify, don't change).
- GraphQL envelopes are LIVE-VERIFIED shapes — copy fixtures from `d3BarChart/__tests__/d3BarChart.graphql.test.js` (aggregate: `uiapi.aggregate.<Object>.edges[].node.aggregate.…` with the extra `aggregate {}` wrapper) and `graphqlService.js` (records: `uiapi.query.<Object>.edges[].node.<field>.value`). Never guess an envelope; new envelope shapes must be verified against the AGENT org before dependent work merges.
- In every graphql wire handler: reset `this.chartRendered = false` after assigning chart data (without it the SVG never initializes).
- Plan-prescribed expected test values are HYPOTHESES — verify against the real service at RED time; if the plan differs, fix the test and report the evidence (repo CLAUDE.md rule).
- Cloned components MUST pass the repo Chart-Clone Hygiene Checklist (4 grep scans) before DONE.
- TDD throughout: failing test → run to see RED → minimal code → GREEN → refactor → commit.
